# 02 — Historias de usuario

Formato: **Como [actor], quiero [acción], para [beneficio].**

## Historias principales

| ID | Actor | Historia de usuario |
|---|---|---|
| HU01 | Profesional | Como profesional, quiero registrar mi perfil con mi rubro, zona de atención y contacto, para que los clientes puedan encontrarme. |
| HU02 | Cliente | Como cliente, quiero buscar profesionales por rubro, zona o nombre, para encontrar a alguien que atienda cerca de mi vivienda. |
| HU03 | Cliente | Como cliente, quiero ver el promedio de calificación y el número de reseñas de cada profesional, para decidir a quién contactar. |
| HU04 | Cliente | Como cliente, quiero calificar a un profesional con estrellas y un comentario, para compartir mi experiencia con otros clientes. |
| HU05 | Cliente | Como cliente, quiero contactar al profesional por WhatsApp con un clic, para coordinar el servicio directamente. |
| HU06 | Administrador | Como administrador, quiero revisar y dar de baja perfiles o calificaciones reportadas, para mantener la confianza en la plataforma. |

## Historias complementarias

| ID | Actor | Historia de usuario |
|---|---|---|
| HU07 | Cliente / Profesional | Como usuario, quiero registrarme e iniciar sesión, para acceder a las funciones de mi rol de forma segura. |
| HU08 | Profesional | Como profesional, quiero editar mi perfil o darme de baja, para mantener mis datos actualizados o dejar de aparecer en el directorio. |
| HU09 | Cliente | Como cliente, quiero saber cuándo un profesional aún no tiene calificaciones, para no confundirlo con uno mal calificado. |
| HU10 | Cliente | Como cliente, quiero que no se permitan calificaciones repetidas o fraudulentas, para confiar en la reputación mostrada. |
| HU11 | Cliente | Como cliente, quiero reportar un perfil o una reseña falsa o inapropiada, para alertar al administrador. |
| HU12 | Cliente | Como cliente, quiero describir mi problema con mis palabras y recibir el rubro sugerido, para no tener que saber qué tipo de profesional necesito. |
| HU13 | Cliente | Como cliente, quiero confirmar o cambiar el rubro sugerido por la IA, para que la decisión final sea mía. |
| HU14 | Administrador | Como administrador, quiero conocer los rubros más buscados en un periodo, para entender la demanda de servicios en la ciudad. |
| HU15 | Administrador | Como administrador, quiero identificar las zonas con pocos profesionales en un rubro, para detectar dónde falta oferta. |
